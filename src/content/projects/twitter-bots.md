This project involves working with the <a href="https://github.com/duo-labs/twitterbots" target="_blank" rel="noopener noreferrer">duo-labs</a> framework to classify and identify Twitter bots using Machine Learning classifiers such as Logistic Regression, Naive Bayes, Decision Trees, AdaBoost, and Random Forest. These classifiers have been implemented in R, with feature extraction methods written in Python, Scala, and Spark. The specifics of the project involved improving the framework and running various benchmarking tests to compare the performance of the techniques in this framework versus Indiana University's <a href="https://botometer.osome.iu.edu/" target="_blank" rel="noopener noreferrer">Botometer</a>.
